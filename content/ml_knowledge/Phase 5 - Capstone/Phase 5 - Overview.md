# 🟢 Phase 5: Capstone Project

> [!INFO] 📌 เป้าหมายของ Phase 5 (สัปดาห์ที่ 15)
> เฟสสุดท้ายนี้คือเวทีแสดงความสามารถของคุณในการสร้าง **End-to-End AI & Machine Learning Project** ตั้งแต่การวางแผนสถาปัตยกรรมระบบ การรวบรวมข้อมูล การฝึกสอนและวิศวกรรมโมเดล ไปจนถึงการทำ Containerization, การขึ้นระบบ API Serving หน้าบ้าน-หลังบ้าน และระบบ Monitoring เพื่อใช้เป็นผลงานชิ้นเอก (Masterpiece Portfolio) สำหรับสมัครงานตำแหน่ง Senior ML / AI Engineer

---

## 🗓️ เนื้อหาใน Phase 5

### [[Week 15 - End-to-End Capstone Project]]
* **ทฤษฎี (2 ชม.):** การวางแผนและออกแบบโปรเจกต์ AI ระดับ Enterprise ตั้งแต่ต้นจนจบ
* **Workshop 1:** ออกแบบ System Architecture & Problem Framing
* **Workshop 2:** พัฒนา Model Training & Evaluation Pipeline
* **Workshop 3:** พัฒนา Backend Serving API (FastAPI / Triton) & Frontend UI (Streamlit / Next.js)
* **Workshop 4:** ติดตั้ง CI/CD, Automated Monitoring และเตรียม Presentation โชว์ผลงาน
