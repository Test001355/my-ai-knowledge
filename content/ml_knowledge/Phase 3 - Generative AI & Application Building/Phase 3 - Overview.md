# 🟢 Phase 3: Generative AI & Application Building

> [!INFO] 📌 เป้าหมายของ Phase 3 (สัปดาห์ที่ 9-11)
> ในเฟสที่สามนี้คือการก้าวสู่ยุค **Generative AI** อย่างเต็มตัว โดยคุณจะได้เรียนรู้การเจาะลึกการทำงานของ Large Language Models (LLMs), การเชี่ยวชาญเทคนิค **Prompt Engineering**, การสร้างระบบค้นหาตอบคำถามอัจฉริยะ **RAG (Retrieval-Augmented Generation)** และการพัฒนา **Autonomous AI Agents** ที่สามารถใช้เครื่องมือและลงมือทำงานเองได้จริง

---

## 🗓️ ตารางเรียนและเนื้อหาใน Phase 3

### [[Week 9 - Generative AI & Prompt Engineering Masterclass]]
* **ทฤษฎี (2 ชม.):** หลักการทำงานของ LLMs, รูปแบบ Prompt Engineering, ค่า API พารามิเตอร์ (Temperature, Top-P)
* **Workshop 1:** การเรียกใช้ LLM ผ่าน API (OpenAI / Anthropic / Gemini API)
* **Workshop 2:** ฝึกทักษะ Zero-Shot, Few-Shot และ Chain-of-Thought (CoT) Prompting
* **Workshop 3:** การบังคับให้ LLM ตอบกลับเป็น Structured Data (JSON format)
* **Workshop 4:** สร้าง Chatbot UI ส่วนตัวด้วย Streamlit

---

### [[Week 10 - Retrieval-Augmented Generation (RAG)]]
* **ทฤษฎี (2 ชม.):** ข้อจำกัดของ LLM (Hallucination), คอนเซปต์ RAG, Vector Databases
* **Workshop 1:** การสร้าง Text Embeddings และการทำ Chunking เอกสาร PDF
* **Workshop 2:** การบันทึกและค้นหาข้อมูลใน Vector Database (ChromaDB หรือ Pinecone)
* **Workshop 3:** การต่อจิ๊กซอว์สร้างระบบ Basic RAG (ดึงข้อมูล $\rightarrow$ ส่งให้ LLM ตอบ)
* **Workshop 4:** การเพิ่มประสิทธิภาพ RAG (Advanced RAG: Re-ranking & Query Expansion)

---

### [[Week 11 - AI Agents & Model Customization]]
* **ทฤษฎี (2 ชม.):** แนวคิด AI Agents, Function Calling / Tool Use, PEFT & LoRA Fine-tuning
* **Workshop 1:** การใช้ OpenAI Function Calling (ให้ LLM เรียกฟังก์ชัน Python)
* **Workshop 2:** สร้าง Autonomous Agent อย่างง่ายโดยใช้ LangChain / LangGraph
* **Workshop 3:** ทำความเข้าใจทฤษฎีการลดพารามิเตอร์ด้วย LoRA (Low-Rank Adaptation)
* **Workshop 4:** จำลองกระบวนการ Fine-tune ด้วยไลบรารี PEFT & Transformers
